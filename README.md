# 📝 Quora Clone - CRUD App (Node.js + Express + EJS)

This is a simple CRUD (Create, Read, Update, Delete) web application built using Node.js, Express, and EJS.
It allows users to create, view, edit, and delete posts — similar to a basic Quora-style platform.

---

## 🚀 Features

- ✅ Create a new post
- ✅ View all posts
- ✅ View a single post in detail
- ✅ Edit existing posts
- ✅ Delete posts
- ✅ Clean UI using CSS
- ✅ RESTful routing
- ✅ Method Override (for PATCH & DELETE)

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express
- **Frontend:** EJS (Embedded JavaScript Templates)
- **Styling:** CSS
- **Other:** UUID, Method-Override

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/quora-clone-crud-app.git
```

2. Navigate into the project folder:

```
cd quora-clone-crud-app
```

3. Install dependencies:

```
npm install
```

4. Run the server:

```
node index.js
```

5. Open in browser:

```
http://localhost:8080/posts
```

---

## 📌 Important Note

- Data is stored in memory (no database used).
- Restarting the server will reset all posts.
